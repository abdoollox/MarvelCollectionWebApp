# Rasmlar

Ikki xil rasm kerak — ular boshqa-boshqa joyda ishlatiladi.

| | Papka | Nisbat | Qayerda ko'rinadi |
|---|---|---|---|
| Poster | `img/<id>.jpg` | **2:3** vertikal | WebApp katalogidagi kartalar |
| Thumbnail | `img/wide/<id>.jpg` | **16:9** gorizontal | Botdan ulashilgan karta |

Chatda gorizontal rasm to'g'ri ko'rinadi, vertikal poster esa haddan
tashqari baland chiqib ketadi — shuning uchun ikkitasi alohida.

**O'lchamlar:**

- Poster: 400x600 yoki 500x750 px, 60-120 KB
- Thumbnail: 1280x720 yoki 960x540 px, 80-150 KB
- Ikkalasi ham JPG, nomi kichik harflarda va aniq mos kelishi shart

Rasm yo'q bo'lsa hech narsa buzilmaydi: WebApp kartada film raqami
ko'rsatadi, ulashilgan karta esa rasmsiz matn ko'rinishida chiqadi.
Bittalab qo'shsangiz ham bo'ladi — bot har 6 soatda tekshiradi.
